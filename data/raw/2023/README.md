# 2023 Dataset Overview

The `2023` directory is composed of 5 CSV files.

---

## environmental2023.csv

Contains data generated by a **Milesight EM500 CO2** device:

- Timestamp (ms)
- Device identifier
- CO2 level (ppm)
- Barometric pressure (hPa)
- Air temperature (°C)
- Air moisture (%RH)

**Location:**
- Latitude: 44.809362
- Longitude: 10.273168

**Sampling rate:** every 10 minutes

---

## indicators2023.csv

Contains daily agronomic indicators, calculated through the Agriware platform for the experimental crop, in the monitoring period:

- Growing Degree Days (GDD)
- Heat Units (6 methods)

**Fields:**
- Midnight timestamp (ms)
- GDD value
- Standard Day Degree (°C)
- Daily mean temperature (°C)
- Daily max temperature above base (°C)
- Daily max temperature (°C)
- Daily max above base with cutoff reduction (°C)
- Ontario unit (°C)

**Sampling rate:** once per day

**Parameters:**
- Base temperature (T_base): 10°C
- Cutoff temperature (T_cutoff): 32°C

---

## soil2023.csv

Contains data from **3 Milesight EM500 SMTC** devices (one per line):

- Timestamp (ms)
- Device identifier
- Line (number)
- Soil electrical conductivity (μS/cm)
- Soil moisture (%RH)
- Soil temperature (°C)

**Locations:**
- Line #1 → (44.808729, 10.272965)
- Line #2 → (44.808726, 10.273005)
- Line #3 → (44.808723, 10.273045)

**Sensor depth:** 20 cm
**Sampling rate:** every 10 minutes
