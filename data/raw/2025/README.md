# 2025 Dataset Overview

The `2025` directory is composed of 9 CSV files.

---

## environmental2025.csv

Contains data generated by a **Milesight EM500 CO2** device:

- Timestamp (ms)
- Device identifier
- CO2 level (ppm)
- Barometric pressure (hPa)
- Air temperature (°C)
- Air moisture (%RH)

**Location:**
- Latitude: 44.80796
- Longitude: 10.27318

**Sampling rate:** every 10 minutes

---

## fruit2025.csv

Contains data from **5 DL-IFD-001 Fruit Dendrometer** devices (one per line):

- Timestamp (ms)
- Device identifier
- Line (number)
- Fruit size (mm)

**Locations:**
- Line #1 → (44.80837, 10.27159)
- Line #2 → (44.80836, 10.27163)
- Line #3 → (44.80836, 10.27168)
- Line #4 → (44.80835, 10.27172)
- Line #5 → (44.80835, 10.27176)

**Sampling rate:** every 10 minutes
**Measurement range:** 7–45 mm

---

## indicators2025.csv

Contains daily agronomic indicators, calculated through the Agriware platform for the experimental crop, in the monitoring period:

- Growing Degree Days (GDD)
- Heat Units (6 methods)

**Fields:**
- Midnight timestamp (ms)
- GDD value
- Standard Day Degree (°C)
- Daily mean temperature (°C)
- Daily max temperature above base (°C)
- Daily max temperature (°C)
- Daily max above base with cutoff reduction (°C)
- Ontario unit (°C)

**Sampling rate:** once per day

**Parameters:**
- Base temperature (T_base): 10°C
- Cutoff temperature (T_cutoff): 32°C
